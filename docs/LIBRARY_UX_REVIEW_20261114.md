# 動畫素材庫 UI/UX 修整（2026-11-14）

基準：ca9e49a。依使用者提供的約23秒錄影，學習效果辨識、直接操作與回饋；沒有抓取或複製參考站Prompt、程式、SVG或素材。這是既有側欄修整，不另建素材網站，不擴增動畫Preset。

## 第一輪：閱讀與辨識

原本兩欄側面板將128px頁面縮為0.6倍，複雜效果甚至縮為0.52倍。16px正文實際約9.6px，效果常只剩相同的Aa與橫線，使用者難以理解差異。

改為原生尺寸的單欄預覽，不使用transform縮放。正文16px、名稱14px、說明13px，操作目標至少44px。使用原創、可辨識的繁中示意：淡入句子、向上回位、重點卡片、三步依序呈現、沿弧線文字、0→128計數、兩面卡片及標籤集合。示意明確標記為非使用者內容，仍經同一PageSchema與PageRenderer。

翻面與折頁直接提供實際按鈕，移除「先重播展開、再操作、再收合」的額外步驟。預覽占用空間從一開始固定，懸停或重播不改變卡片尺寸；主工作區與側欄寬度不變。單欄增加捲動距離，交換可讀性；沒有為了多放素材壓縮主要畫布。

## 第二輪：直接操作與範圍

實測指出物理場的入口在底部、標籤在上方，手機側欄很難同時看到。現在在素材預覽將入口放上方，場景採180px實際viewport，字型與座標不縮放。共用PhysicsTags從可信CSS viewport讀取高度並限制160–400px；正式網站／匯出仍預設280px，沒有新增PageSpec參數或任意CSS輸入口。

三尺寸量測均得到：Canvas 180px、按鈕44px，兩者完整位於252px預覽內。進入／退出拖曳會切換none／pan-y，Reduced Motion則回到文字列表。

另外發現懸停效果按「重播」時，指標仍停在按鈕上，示意沒有實際進入hover。改成「試玩」，聚焦同一Runtime的真實效果元件，以既有focus回饋體驗浮起與光暈；不是另外寫一套假效果。鍵盤可操作，Reduced Motion取消位移，預覽連結不能開外站。

原本全素材共用replay key，重播一項會重建其他示意。現在每個Preset獨立key；測試確認其他示意的UUID保留。清除舊的縮圖與展開CSS，避免新舊規則互相覆寫；素材專用樣式不再隨Runtime CSS匯出。

## 驗證及界線

- 原生預覽16px、操作目標44px、重播不位移、不重建其他示意、三尺寸直接翻面／折頁／標籤、Reduced Motion、無外部生成POST與無瀏覽器例外：由新增4個Chromium測試驗證。
- 完整回歸涵蓋原有拖放、Patch、Undo/Redo、Session／Revision／CAS、圖片、Mock候選、保存重載與React獨立匯出。最終測試數及Commit見STATUS.md最新段落。
- 沒有新增產品依賴、沒有付費API、沒有部署。原始截圖與量測在/workspace/backups/library-polish-20261114/，沒有手動美化。
- 單欄12項需要捲動；這是明確的可讀性取捨，不宣稱同時看見全部素材。實體裝置觸感、螢幕閱讀器與個人美感不是headless測試能證明的事項。物理與折頁的既有模型限制見MOTION_LIBRARY_REVIEW.md。
