## 參考了什麼
- `docs/DECK_REFERENCE.md`：開場故意無聊（第 2 頁三個長得差不多的網站示意，不用漸層或 emoji）、一頁一個重點、講者備註寫成舞台指示。結尾不收口號，講完就結束
- 使用者提供的 presentation-master skill：黃金三圈定主軸、RUBA（記住／了解／相信／行動）、每頁結論式標題＋證據、計時
- vocus〈不會寫程式也能做教學動畫〉：先做無聲「字幕版」審片，再配音；意見用「時間點＋問題＋想要的樣子」
- avoid-ai-writing：不誇大、不捏造數字、沒來源的說法不寫、避免制式開場與過多粗體
