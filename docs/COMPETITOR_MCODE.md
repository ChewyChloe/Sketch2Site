# 競品分析：Mcode（MiniMax Code）作品集教學（2026-11-24）

資料來源：使用者轉述的社群教學（未實際操作 Mcode，以下對 Mcode 的描述以該教學為準）。

## Mcode 的做法
1. Goal 模式：AI 自己復盤、反覆修改直到達成目標。
2. 上傳參考圖，AI 拆解每個區塊該放什麼。
3. 加 frontend-design 技能生成網站骨架（產出程式碼）。
4. 注釋：點選頁面元素，告訴 AI 怎麼改。
5. 選取區域貼上動效 prompt。
6. 再用 Goal 模式整體檢查間距與互動。

限制：要下載桌面客戶端（網頁版沒有 Goal 與注釋）、用積分計費（初版約 300 積分）、國內外版本功能不同、產出的是程式碼，修改與部署仍要面對程式。

## 我們已經做到的（DONE）
| 需求 | Mcode | Sketch2Site |
|---|---|---|
| 開始方式 | 寫 prompt、上傳參考圖 | 拖拉草稿＋填空描述（不會寫 prompt 也能用） |
| 注釋改哪裡 | 需桌面版、每次呼叫 AI 扣積分 | 瀏覽器內點選元素→註解泡泡；常見說法本機即時解讀，免費、離線可用、一句話可多個修改 |
| 修改安全 | AI 改程式碼，可能動到其他地方 | 每個修改都是受檢查的 Patch，只能改選取範圍，可「撤銷修改」 |
| 內容 | AI 可能自己改寫文案 | AI 不能新增或改寫使用者文字；改文字只接受使用者引號內的字 |
| 動效 | 每次自己寫動效 prompt | 60 種現成動畫庫；範本與新區塊自動依區塊挑選，也能用註解說「加百葉窗」 |
| 安裝 | 下載客戶端 | 免安裝，資料存在自己的瀏覽器 |
| 成果 | 程式碼 | 預覽網站＋可匯出 React 專案，多頁面、表單 |

## 還沒做到、可以超越的（NOT STARTED）
1. 「一鍵整體檢查」：取代 Goal 模式的全局巡檢，但用規則而非 AI——檢查間距不一致、對比不足、圖片沒有替代文字、按鈕文字太模糊、標題斷行，列出問題並可一鍵修正。免費、可預期。
2. 註解的 AI 後備：本機看不懂的自由描述才送 AI，AI 只能回傳受檢查的 Patch（同樣不能改寫文字）。需要使用者另行授權付費測試。
3. 參考圖／手繪草稿拍照轉草稿（使用者先前決定延後）。
4. 一鍵發佈網址。
