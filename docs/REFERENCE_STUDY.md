# 參考網站研讀（2026-11-26）

使用者提供 12 個網站。每個都用瀏覽器實際打開、捲動，截了桌面與手機畫面。只學原則，不抄畫面、文字或素材。

## 最重要的結論

好看不是因為「乾淨」，而是**每個網站都有一個概念，所有元素都服從它**。粗框、斷字、亂排都可以好看，前提是有主張而且一致。我們的舊網站是「首屏／特色／價目／行動呼籲」照順序排，沒有概念。

## 共同規律

1. 一個概念貫穿全站。
2. 字的大小對比極端（300px 對 11px）；名字常用寬字距大寫；等寬字、個性字常見。
3. 黑或白加 0～1 個點綴色，或一個大膽底色。
4. 圖是主角，而且是真的好圖。
5. 介面極少：導覽 3～4 個小字放角落。
6. 細節語言：編號、細線、圖說、小字註記。

## 落實到 Sketch2Site

- 「設計概念」層（pageSpec `conceptIds`、`[data-concept]`）：一次決定字體、編號、線條、導覽、圖片處理。第一個是「展覽空間」，之後依序：研究檔案、作品牆、單色海報、暗場、生成網格。
- 開源英文展示字型自帶（Hanken Grotesk、Instrument Serif、Space Mono，SIL OFL，只有拉丁字母），中文用系統字。
