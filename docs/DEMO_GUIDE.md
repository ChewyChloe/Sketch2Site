# 免費展示操作

所有展示草稿及「示範排版」均為本機範例，不代表真實AI生成能力。不需API Key或生成後端；原圖不會上傳。本輪真實付費生成仍NOT TESTED。

1. 開啟「草稿選單」→「載入個人作品集」。活動介紹、不規則草稿、動畫草稿可同樣重複載入。未保存內容被取代前會詢問，載入可用「還原」復原。
2. 拖動標題，修改文字；需要自己的圖片時，展開側欄「元件」→「匯入圖片」。支援PNG／JPEG原圖5MiB內，最長1600px、轉換後2MiB、總共10張／20MiB，僅保存在此瀏覽器。按「儲存草稿」，或在文字欄位內使用Ctrl／⌘+S。
3. 「草稿選單」→「示範排版（非 AI）」。此功能使用確定性的簡單布局，不理解自然語言；草稿需符合既有40元素／12000字生成限制。檢視候選的桌面／手機版，選「使用此版本」才保存正式頁面。返回草稿不改寫已保存頁面。
4. 在預覽按「選取」，點標題→「工具／屬性」改文字並「套用」。開「動畫」，拖曳淡入至標題，或直接選擇效果。僅六種受控Preset；依序顯示限相容容器。可移除、更換、撤銷與重做。
5. 「畫筆」圈註重點，可撤銷或清除；這些註記不會進入匯出網站。Esc取消選取、關閉工具並回到瀏覽。手機工具在下方，上方保留可捲動預覽；按工具區「關閉」或Esc後可恢復整頁面積。尚未套用時，Esc／換選取前會詢問是否捨棄，取消會保留輸入。
6. 等待唯一保存狀態「已儲存」，可「頁面／重新載入頁面」確認保存。最後「頁面／匯出 React 專案」下載ZIP；解壓後用Node24執行`npm ci`、`npm run build`、`npm run preview`。首次依賴安裝需npm網路，建好的網站不需Sketch2Site後端。ZIP不含草稿、註記、歷史、API Key或生成程式。

本機資料不是雲端備份，清除瀏覽器資料會移除圖片。為保留Undo可能引用的圖片，暫不提供自動清理；達上限可在圖片屬性重用已匯入素材。請下載ZIP保存目前網站。

「生成網站」是正式AI管線入口，本展示不使用。未配置後端時會提示不可用並保留內容，可繼續使用非AI示範、編輯、保存與匯出。不可將示範結果或Mock測試的虛構token估計當作真實模型品質或費用。
