# Phase 6.1 工作台 UI/UX 修整

2026-11-10（Asia/Taipei）。基準Commit：ac3d5de681b3a78a7cc88961894457ee633c0032。工程修整與測試完成後交由使用者驗收；不宣稱已達產品級設計品質。

## 實際調整

- 預覽原本的來源／尺寸／操作列、模式列和保存列合併為一條48px情境列。來源／保存移至主要應用列；移除預覽底部的草稿狀態，避免同時顯示兩種保存狀態。
- 來源、專案與草稿／預覽仍在應用列；載入／還原／重新載入集中於「頁面」，尺寸切換／動畫重播位於「檢視」，保留文字名稱與選單可存取性。
- 元件清單、動畫素材、屬性共用右側分頁。元件清單的按鈕沿用穩定ID，也可用鍵盤操作，移除與清單重複的元件下拉。
- 六動畫改為二欄素材格，含SVG識別、拖曳把手、靜態縮圖、短名稱與相容性文字。懸停／聚焦時才以既有Renderer示範效果；沒有新Preset、新keyframes系統或AI生成素材。
- 屬性欄依「選取元件 → 常用欄位 → 已附加動畫 → 套用」排序；移除獨立淡入checkbox。時長與文字可同一批套用，動畫替換／移除仍各自可Undo。修改紀錄收合且使用中文名稱。
- 1000px以下預設不開側欄，點選元件不自動遮住預覽。開啟後可用關閉按鈕退出；拖曳時面板暫退到邊緣。375px不再常駐下方編輯區，工具圖示有可存取名稱及原生title。
- 草稿也使用收合策略，避免小螢幕被304px側欄擠成狹窄長條；空白提示依可視寬度與原縮放比例顯示，沒有改動草稿尺寸與拖曳座標。修正drop之後視覺拖曳狀態未結束，在960px仍將側欄推出視窗的問題；測試同時檢查拖曳狀態清除與頁面寬度。
